# Roasty 🌱🔥

Welcome to **Roasty**! This is a fun, interactive botanical quiz application built with modern web technologies. 

## 🎯 What is Roasty?

Roasty tests your knowledge of plant taxonomy. You are presented with the common name of a plant (like "Mango" or "Potato") and you must guess its scientific botanical name (like "Mangifera indica" or "Solanum tuberosum").

But beware! The game features a sassy animated plant that will playfully "roast" (insult) you if you guess incorrectly!

**Key Features:**
- **Interactive Quiz:** Guess the botanical names of common plants.
- **Sassy Feedback:** Get "roasted" by an animated plant for wrong answers.
- **Streak Tracking:** Keep track of your correct answer streaks and progress.
- **Memory Bubbles:** Visually track your past attempts floating on the screen.

## 🛠️ Tech Stack

This project is built using a modern frontend stack:
- **Vite:** Next-generation frontend tooling for fast builds.
- **React 18:** For building the interactive user interface.
- **TypeScript:** Adding static typing for robust code.
- **Tailwind CSS:** Utility-first CSS framework for rapid styling.
- **Framer Motion:** For smooth, fluid animations (like the floating memory bubbles and plant moods).
- **shadcn/ui & Radix UI:** Unstyled, accessible UI components.

## 🚀 Getting Started

To run this project locally, you'll need Node.js and npm installed.

```bash
# Step 1: Clone the repository (if you haven't already) and navigate to it
cd Roasty

# Step 2: Install dependencies
npm install

# Step 3: Start the development server
npm run dev
```

The app will start with auto-reloading and an instant preview. Open your browser and navigate to the local URL provided in your terminal (usually `http://localhost:5173` or `http://localhost:8080`).

Enjoy getting roasted by plants! 🌿🔥
